Getting a quote

How should file revisions be managed?

Use a new, clearly identified package for every material change and confirm which revision the quotation and production release cover.

✓ Reviewed August 15, 2026
⌕

Direct answer

When any fabrication file, stack-up, material, quantity, test, or documentation requirement changes, send a clearly identified replacement package and list the changes. Ask HXLFAB to confirm whether the change affects feasibility, price, or schedule before production release.

A controlled revision message

State the new revision identifier, date, and reason for change. Explicitly say which earlier package is superseded and whether the change is expected to affect the quoted construction.

  • Use one consistent revision identifier across data and drawings
  • Include a short change list
  • Remove obsolete files from the replacement archive
  • Reconfirm quantity and any date constraint
  • Request written acknowledgement of the released revision

Changes that may require a revised quote

Layer construction, dimensions, material, copper weight, via structure, impedance, surface finish, quantity, testing, reporting, and packing can all change the manufacturing or commercial route. Impact is confirmed case by case.
