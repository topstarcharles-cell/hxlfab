How should I package Gerber or ODB++ data?

Submit one self-contained package with matching fabrication, drill, outline, drawing, and revision information; compress ODB++ folders before upload.

✓ Reviewed August 15, 2026
⌕

Direct answer

Create one self-contained archive for the quoted board revision. Include the fabrication layers, NC drill data, outline, drawing or notes, stack-up, and any supporting impedance or via table. ODB++ folders should be compressed into ZIP or 7Z before website upload.

Before compressing the package

Open the exported dataset in an independent viewer where possible and compare it with the intended board. The website accepts files for review; it does not validate that the exported manufacturing data represents the design intent.

  • Confirm all copper, mask, legend, paste-if-relevant, and profile layers
  • Match plated and non-plated drill data to the drawing
  • Remove unrelated designs and obsolete revisions
  • Use readable layer names and include a readme for non-obvious naming
  • Confirm units and zero suppression where applicable

Archive and upload limits

The current RFQ supports ZIP, 7Z, RAR, TGZ, GZ, and TAR archives plus listed PCB and document file types. It accepts up to 10 files, 100 MB per file, and 200 MB total. A single related archive usually makes revision control easier.
